# YZUA v0.5

YZUA = **Yangzhou University Agent**，面向扬州大学的校园课表、成绩和考试管理 Android 应用。

## 本版内容

- 应用桌面名称、登录页、首次引导和“我的”默认名称统一为 YZUA。
- Android 版本 `0.5.0`，versionCode `5`；applicationId 保持 `cn.yzu.timetable`。
- 包含已由用户测试通过的 SSO 登录修复：分阶段填表和官方按钮单次提交、认证结果检测、超时提示、学校网页登录备用入口。
- 启动进入“今日”，本地保存课表、成绩和考试查询结果；仅在需要刷新时登录。
- 底栏为“今日 / 课表 / 成绩 / 考试 / 我的”，智能助手保留为“我的”子页面。
- 保留 URP 返回的学年、教学周及节次时间解析和学期日期校准。

## 安装与验证

下载 `YZUA-v0.5.apk`；`SHA256SUMS.txt` 用于核对下载文件。APK 由本次 GitHub Actions 的 `assembleDebug` 生成，使用 Debug 签名，尚未配置正式发布密钥。不同 Actions 构建的 Debug 签名可能不同；如系统拒绝覆盖安装，请先保留旧应用中的重要信息，再决定是否卸载（卸载会清除本地缓存）。

手机连接校园网或可访问教务的 VPN 后，在“我的”登录；有验证码或自动认证异常时选择学校网页登录。电脑 VPN 不会自动共享给手机。

构建工作流执行 SSO JavaScript 行为测试、Android 单元测试、APK 编译和 Lint。此前登录修复已获用户实测通过；此次改名发布仍需对发布 APK 做手机安装验收。真实非空考试记录格式仍受现有样例限制。
