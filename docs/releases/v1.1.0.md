# YZUA v1.1.0

## 新功能与改进

- **教室信息完整显示**：今日与课表中不再截断楼栋（如“扬子津东校区 文津楼 N104”）。
- **显示模式**：更多 → 显示模式，可切换日间 / 夜间 / 跟随系统，立即生效并保存。
- **自定义课表**：课表设置中可按名称、星期、节次、地点、教师添加课程，与教务课表一同显示在课表、今日和课程详情中；仅保存在本机。
- **开屏页**：冷启动约 2 秒展示张謇先生训辞“坚苦自立”（中国红 #C3272B，取自手书扫描件），背景与 App 风格统一。
- **检查更新**：每次冷启动自动查询 GitHub Releases（6 秒超时，失败仅弱提示，不影响使用）；更多 → 检查更新可开关自动检查、手动检查并跳转下载。
- **上课提醒修复与增强**：新增每日自愈闹钟与课中静音状态同步；今日设置中可查看“提醒队列”（接下来几条提醒的时间与课程）并发送测试通知，便于排查权限问题。

## 安装

下载 `YZUA-v1.1.0.apk`（正式签名，与 v1.0.0 同密钥），可直接覆盖安装；`.sha256` 用于核对。
