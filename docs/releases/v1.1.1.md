# YZUA v1.1.1

## 修复与改进

- **教室楼名补全**：经抓包核对，教务接口把楼名放在 `teachingBuildingName` 字段，此前被丢弃；现在地点显示为“校区 + 楼 + 教室”全称（如 扬子津东校区 文津楼 N104）。旧缓存中的地点仍是短名，需在“我的”中重新登录刷新一次。
- **修复“显示模式”“检查更新”点不开**：两个入口的回调此前未接到底栏路由，现已接通。
- **自定义课表编辑器重做**：圆角玻璃输入框、玻璃胶囊节次下拉与星期选择、周次支持每周/单周/双周/自选（自选可逐周点选）；以底部弹层呈现，去掉“添加”按钮外的白框。
- **开屏字矢量化**：“坚苦自立”改为矢量图（由手书扫描件描摹），任意分辨率下清晰。

## 安装

下载 `YZUA-v1.1.1.apk`（正式签名，与 v1.0.0 / v1.1.0 同密钥），可直接覆盖安装。
