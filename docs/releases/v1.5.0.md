# YZUA v1.5.0

## 新功能

- **智能助手**（更多 → 智能助手）：自配 OpenAI 兼容接口（默认 DeepSeek 地址，设置内含 api-docs.deepseek.com/zh-cn 跳转引导与“获取模型列表”按钮）；ReAct 工具循环可查询今日/某周课表、下一节、成绩、考试、学期信息、空闲教室，并能按对话把课程写入自定义课表；回复支持 Markdown 渲染。密钥仅存本机。
- **查找空教室**（更多 → 查找空教室）：校区 → 教学楼 → 今天/明天/后天 → 起止节次，实时查询教务接口，按楼分组显示空闲教室与座位数。
- **自定义课表**：课表设置中按名称、星期、节次、地点、教师、周次（含逐周自选）添加课程，并入课表与今日。
- **开屏页**：冷启动约 2 秒展示矢量“坚苦自立”（中国红 #C3272B）。
- **显示模式**：更多 → 显示模式（日间/夜间/跟随系统）。
- **检查更新**：冷启动自动检查 GitHub Releases，可开关；失败仅弱提示。
- **上课提醒 / 上课自动静音**：今日右上角设置；提醒队列可见、支持测试通知；每日自愈闹钟与课中状态同步。

## 修复与优化

- 教室地点显示全称（校区+楼+教室，楼名取自 teachingBuildingName 字段）。
- 学期校准结果在重新登录后保留；仅当本机日期超出学期范围时提示校准。
- 课表页在开屏期间预渲染，首次切换不再卡顿。
- 周次切换单击即时响应；助手页返回键缩小；“添加”按钮白框移除。

## 安装

下载 `YZUA-v1.5.0.apk`（正式签名，与 v1.0.0–v1.1.1 同密钥），**可直接覆盖安装，无需卸载**，本地课表与校准保留。`.sha256` 用于核对。
