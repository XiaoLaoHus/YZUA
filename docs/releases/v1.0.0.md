# YZUA v1.0.0 正式版

YZUA = **Yangzhou University Agent**，面向扬州大学学生的课表、成绩和考试 Android 应用。个人开发的学习研究项目，与扬州大学无任何关联。

## 新功能

- **液态玻璃界面**：全新视觉，实时模糊与边缘折射（Android 12+ / 13+），浮空椭圆底栏，弹性切换动画，完整深色模式。
- **底栏简化**为 今日 / 课表 / 更多 / 我的；成绩、考试、智能助手（即将上线）、查找空教室（即将上线）和关于页面移入“更多”。
- **扬大上课时间表**：按 2025 学生手册的春夏季（5 月 1 日起）/ 秋冬季（10 月 1 日起）作息自动切换节次时间。
- **今日**：按本机时间分为正在上课 / 待上 / 已上，正在上的课程显示进度条；强调时间、地点与课程名。
- **课表**：整周一屏显示，左右滑动切换周次，可隐藏周末，清晰的节次时间与午休/晚饭分隔、当前时间线。
- **学期校准**：日历点选开学第一周和最后一周，第一学期默认推荐包含 9 月 1 日的那一周。
- **上课提醒**：课前推送课程、时间与地点，可设置提前 5/10/15/30 分钟。
- **上课自动静音**：上课静音（无勿扰权限时改为振动），下课自动恢复。
- 新应用图标、首次使用须知、关于页面，以及与登录页风格一致的统一认证等待页。

## 安装

下载 `YZUA-v1.0.0.apk`，可用同名 `.sha256` 文件核对。

**本版起使用正式签名，与 v0.5 及之前的 Debug 签名不同，无法直接覆盖安装。** 请先卸载旧版再安装（卸载会清除本机保存的课表、成绩与学期设置，安装后在“我的”重新登录导入即可）。之后的版本都可直接覆盖升级。

手机需连接校园网或可访问教务系统的 VPN 后登录；遇到验证码时选择“使用学校网页登录”。部分国产系统需允许 YZUA 后台运行/自启动，上课提醒才能按时送达。
