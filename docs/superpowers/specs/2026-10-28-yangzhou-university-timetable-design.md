# 扬州大学课表管理 App 首版设计

## 意图

为扬州大学学生提供一个与 HITA 相同使用节奏的课表工具：登录后进入今日课程，能按周查看课程、查看课程详情，并为未来的 AI 问答保留明确入口。首版先解决“我今天/这周在哪里上什么课”的高频场景，同时把 URP 接入隔离，便于根据扬大实际部署参数继续适配。

## 目标

- Android 8.0（API 26）及以上可运行。
- 使用 Kotlin + Jetpack Compose + Material 3，保持 HITA 的视觉方向：浅色卡片、蓝紫渐变强调色、圆角、底部导航和周视图网格。
- 提供登录页、课表主页、课程详情页、AI 空白页、设置页。
- 支持学期切换、上一周/下一周、回到本周、课程卡片点击查看详情。
- 登录和课表查询使用 `UrpScheduleDataSource` 抽象；默认实现提供演示数据，真实 URP 实现通过隐藏 WebView 触发扬大 SSO 官方表单，再用内存 CookieJar 查询 URP。
- 用本地 `DataStore` 保存登录状态与最近一次课表，断网时仍能查看缓存。

## 非目标

- 首版不实现 AI 问答、成绩、考试、选课、空教室和消息推送。
- 不把扬大 URP 的账号密码发送到第三方服务；密码只从原生登录表单交给扬大 SSO，并在认证结束后清空。
- 不声称已经接通扬州大学真实 URP；真实接口需要部署地址、登录字段和课表响应样例后再落地。

## 反目标

- 不复制 HITA 的后端或账号体系。
- 不把 URP HTML/JSON 解析写进 Compose 页面。
- 不把一次性的演示课表当作真实教务数据。

## 用户流程

1. 首次打开显示“扬大课表”登录页，输入学号和密码；点击登录后进入课表页。
2. 课表页顶部显示学期、周次和刷新按钮；中间显示周一至周日列和 1-12 节行；课程卡片使用多色板，显示课程名、教室和教师。
3. 点击课程卡片打开详情页，显示时间、周次、教室、教师和课程代码。
4. 底部导航在“课表 / AI 助手 / 我的”之间切换。AI 助手页展示空状态，明确说明功能即将上线。
5. “我的”页显示扬大身份、当前数据源和缓存状态；可退出登录、清空缓存。

## 数据与 URP 边界

领域模型统一为：`Term`、`ScheduleCourse`、`ScheduleLesson`、`UserSession`。

`UrpScheduleDataSource` 提供登录、课表、成绩和考试查询操作。HTTP 实现使用 OkHttp：隐藏 WebView 完成 SSO 官方表单后交接 Cookie，后续请求通过内存 CookieJar；课程响应映射为统一的 `ScheduleLesson`，并解析 `jcsjbs` 节次时间及可用的学年、学期和教学周元数据。接口路径和字段通过 `UrpConfig` 集中配置，不散落在 UI 或 ViewModel 中。

在没有真实扬大接口契约的情况下，`DemoUrpDataSource` 生成一组扬大示例课程，保证 UI 和交互可验收；真实接入只需替换数据源与字段映射，不改页面。

## 视觉与实现决定

- 单模块 Android 应用，包名暂定 `cn.yzu.timetable`。
- Compose Navigation 管理页面；ViewModel 负责状态，Repository 负责数据源和缓存。
- 主题色采用扬大蓝（`#1769AA`）配紫色辅助色，背景为浅灰蓝；深色主题沿用 Material 3 自动映射。
- 课表网格使用自绘 Compose 布局，课程卡片按节次高度占位，支持横向滚动。
- 图标使用 Material Icons Extended；不引入远程图片或需要额外许可的素材。

## 验收标准

- `./gradlew assembleDebug` 成功，生成 debug APK。
- 启动后可完成演示登录并看到有内容的周课表。
- 点击课程能看到详情，底部导航能切换三个主页面，AI 页为空状态清晰可见。
- 退出后重新打开不会泄露密码；无网络时能显示最近一次演示课表。
- URP 真实接口未配置时，界面显示“演示数据”标识，不误导用户。
