# 今日首页与离线查询实现计划

> 使用 executing-plans 逐项实现；用户本轮四项要求为范围依据。保留现有 SSO 与 URP 协议，仅改导航、缓存及日期展示。

目标：启动直接进入今日；登录在我的中按需执行；已导入课表、成绩与考试可离线查看，启动不自动发起认证。

实现决定：底栏为今日 / 课表 / 成绩 / 考试 / 我的；智能入口移到我的子页。首次显示可关闭引导卡，按钮转到我的。退出仅注销临时会话，保留缓存；另设明确的清除本地数据操作。切换账号需先清除旧账号缓存，避免混合展示。

日期规则：使用本机 LocalDate，每分钟及回到前台刷新；今日按星期、实际周次集合筛选，按起止节次排序。学校首页可读到当前周时推算首周周一（仅用于校准建议）；学期结束默认 20 周并明确需校准。无法读取学校周次时不编造日期，显示设置入口。学期首周与结束日期在我的中可编辑，边界以保存的日期为准；到期用非模态提示条引导刷新，不自动弹登录。

数据规则：只缓存查询结果与更新日期，不缓存 Cookie、密码、会话 token。JSON 放应用私有目录，原子替换，损坏回退并明确提示；禁用系统备份。范围不同的成绩独立缓存，失败保留旧数据，成功的空结果也保存。

## 文件与职责

- data/AcademicCache.kt：明确的缓存 DTO、私有文件持久化、损坏检测、原子替换。
- data/AcademicCalendar.kt：学期日期、今日筛选、边界提醒与学校周次解析。
- ui/AppViewModel.kt：启动恢复、显式登录、独立刷新保存、退出保留、清除、时间更新。
- MainActivity / AppViewModelFactory：应用目录注入和本机日期生命周期。
- ui/AppRoot.kt 与 screens：导航、今日列表、引导、刷新登录入口、我的子项和日期设置。
