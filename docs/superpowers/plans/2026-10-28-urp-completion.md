# URP 与课表功能补齐计划

沿用现有 Kotlin/Compose 单模块工程，按用户要求继续实现，不重复需求确认。仅在 YZUA 独立仓库修改和发布。

## 任务

- [ ] 1. 真实课表解析：周次集合、单双周、HTML rowspan、URP JSON；无法识别的页面报错，不能以空课表覆盖缓存。先用脱敏合成样例写测试并看到失败，再实现。
- [ ] 2. URP 网络接入：Cookie 会话、HTTPS、同源检查、登录表单和隐藏字段、验证码网页登录、学期选择、过期识别。用 MockWebServer 验证请求，不复制 GPL 参考代码。
- [ ] 3. 本地缓存和状态：按账号/学期隔离，密码和 Cookie 不落盘；重启可离线看课表；刷新失败保留缓存；取消操作和退出登录不能回写旧请求；用户设置学期首周日期。
- [ ] 4. 界面：对照 HITA 经典样式（参考提交 5ae9a93），今日时间线、周课表、校园入口、AI 空白页、我的页；修正跨节卡片、冲突、周次和学期操作。
- [ ] 5. 验证：单元/网络契约测试、Android Lint、Compose 交互测试和截图；更新中文说明、来源与限制；提交并由 GitHub Actions 编译验证 APK。

## 审查重点

登录页 HTTP 200 不能当作登录成功；空响应或解析失败不能删除旧课表；跨账号缓存不可混用；退出时未完成请求不得恢复登录；证书错误不可忽略；验证码由用户在学校网页完成；真实学校未实测时明确标注。
