# YZUA · Yangzhou University Agent

如你所见，这是一个面向扬州大学学生开发的校园教务系统本地软件，为了不用每天打开浏览器，登录加载缓慢的教务系统而开发。

本软件目前仅支持安卓/鸿蒙（卓易通）设备使用，iOS版本因经费原因暂时无法上架AppStore，所以暂缓开发。

软件灵感基本来自哈尔滨工业大学同学共同维护的项目[HIT-A/HITA_Android](https://github.com/HIT-A/HITA_Android)，本软件取名也源于此处，在此特别鸣谢HITA为本软件提供的UI设计参考

软件目前仍处于测试阶段，由于作者使用大量AI进行辅助编写，所以可能出现各种小问题，如有建议和问题，请通过软件自带的关于页面联系我，或者在Github页面上发Issues，感谢理解！

- 系统要求：Android 8.0（API 26）及以上。

  基本实现原理：

- 应用内 SSO 登录：原生登录页收集学号和密码，由正常手机视口、原生遮罩下的 WebView 承载统一认证页面；先填入正确表单，再等待 Angular 校验完成，只点击一次官方登录按钮，让学校代码完成密码加密。成功回跳教务 `/index` 或 `/mobile/index` 并通过课表 API 验证后，才交接 Cookie 返回 App。密码不写入缓存；遇到验证码、错误或超时停止等待，提供“切换学校网页登录”；登录页也可直接选择学校网页登录。

- 本学期课表：GET 查询，支持位图周次、单双周、课程详情。

- 成绩查询：本学期与全部学期切换，动态发现查询地址；全部学期按页读取，区分等级成绩、未公布、未评估与查询关闭。

- 考试安排：读取考试页和 FullCalendar 事件接口，查询当前月份前三个月到后四个月月初；查询错误和无考试分开显示。

- 各查询独立报错、可刷新；刷新失败保留本地旧数据。启动默认进入“今日”，首次使用只在今日页引导到“我的”完成登录；登录一次后课表、成绩和考试结果保存到应用私有目录，后续启动可离线查看。成绩和考试的最新查询需要在“我的”中重新登录刷新；退出只清理内存会话并保留本地查询结果；再次通过 SSO 登录时，因当前 URP 接口未提供可验证学号，App 会先隔离旧快照，再写入新账号的查询结果。

- 今日按本机日期、已保存学期首周和实际单双周课程筛选，并按节次排序。URP 课表响应中的 `jcsjbs` 会直接提供节次起止时间，同时解析可用的学年、学期和当前教学周，缓存后显示在课表和今日页面。

## 网络与安全性

手机需要连接校园网，或使用可访问教务系统的校园 VPN。电脑已经连接 VPN，不表示手机自动具有同样的网络。

本软件的API Cookie 保存在独立的内存 CookieJar，不写入代码、日志或持久缓存。系统 WebView 在认证过程中可能使用自己的磁盘 Cookie 存储，App 会在开始、完成及销毁登录页时清理；进程异常终止无法保证销毁回调执行。查询结果写入应用私有文件并禁用系统备份；缓存不含 Cookie、密码或会话 token。学期首周和结束日期可在“我的”中校准，学期开始/结束显示提醒但不自动弹出登录页。缓存损坏时回退为空并提示重新导入。
